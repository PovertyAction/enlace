# Paper Extraction Quality Control Checklist

Use this checklist before finalizing any paper extraction to ensure completeness and accuracy.

## Pre-Extraction

- [ ] Paper converted to searchable format (markdown/text)
- [ ] Appropriate template selected (RCT/observational/review)
- [ ] Supplementary materials located and accessible
- [ ] Extraction file created with proper naming convention
- [ ] Extraction date recorded

## Bibliographic Information (10 items)

- [ ] All authors listed with affiliations
- [ ] Complete and accurate title
- [ ] Journal/publisher name correct
- [ ] Year, volume, issue, pages recorded
- [ ] DOI verified and linkable
- [ ] APA citation properly formatted
- [ ] BibTeX entry complete and valid
- [ ] Author keywords extracted
- [ ] JEL codes noted (if applicable)
- [ ] Persistent URL saved

## Research Context (8 items)

- [ ] Background and research problem summarized
- [ ] Research gap clearly identified
- [ ] Primary research question stated
- [ ] Secondary questions listed
- [ ] Hypotheses documented (if stated)
- [ ] Theoretical framework described
- [ ] Contribution to literature noted
- [ ] Page numbers for all items noted

## Scoring

**Total Items**: 200+

**Quality Thresholds**:

- **Excellent**: >95% complete (all critical items)
- **Good**: 90-95% complete
- **Adequate**: 85-90% complete
- **Needs Revision**: <85% complete

**Critical Items** (must complete):

- All results with effect sizes and SEs
- Sample sizes
- Study design details
- Quality assessment
- Key takeaways

**Time to Complete Checklist**: 15-30 minutes

---

## Common Missed Items

Watch out for these frequently overlooked items:

1. **Page numbers**: Often forgotten but crucial for verification
2. **Supplementary materials**: Appendices contain important info
3. **Null results**: As important as significant findings
4. **Attrition details**: Critical for quality assessment
5. **Pre-registration**: Check if PAP exists
6. **Control means**: Needed for effect size interpretation
7. **Robustness checks**: In appendix, easy to miss
8. **Heterogeneity corrections**: Multiple testing adjustments
9. **Standard error type**: Critical methodological detail
10. **Authors' limitations**: Often in last paragraph

## Quick Reference Version

**Minimum extraction** (for screening):

- [ ] Citation, sample size, outcome
- [ ] Main treatment effect with SE and p-value
- [ ] Study design type
- [ ] Quality rating
- [ ] Relevance assessment

**Time**: 30-60 minutes

**Full extraction** (for synthesis):

- [ ] Complete all sections above
- [ ] Thorough quality assessment
- [ ] Critical analysis

**Time**: 3-6 hours

---

## Review Process

### Self-Review

1. Complete checklist immediately after extraction
2. Note any gaps
3. Return to paper for missed items
4. Verify key numbers

### Peer Review (if applicable)

1. Exchange extractions with colleague
2. Verify key results independently
3. Discuss discrepancies
4. Reach consensus

### Quality Audit

- Randomly select 10% of extractions
- Check against paper
- Calculate error rate
- Provide feedback

---

## Notes

**Flexibility**: Not every item applies to every paper. Use judgment.

**Adaptation**: Modify checklist for other study types (observational, review, etc.)

**Iteration**: Update checklist as you identify common issues

**Standards**: Maintain consistent standards across all extractions

**Team Use**: If team extraction, ensure everyone uses same checklist
